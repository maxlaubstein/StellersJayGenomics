## Steller's Jay Principal Components Analysis

This directory contains all code used to run and plot the results of PCA

I ran PCA separately for the whole 310 individual dataset, and the dataset of 306 non-Mesoamerican samples (hence the ```allsamples``` and ```nomeso``` directories, respectively.

In each, the script ```run.sh``` will run PCA with Plink. The script ```plot.r``` makes plots.
